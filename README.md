Two-scale burst rider for cbBTC: it only rides a confirmed burst (30-bar return above +50 bps with the 120-bar return positive), buying 100% of cash, and exits on a 2.5% trailing stop or a −150 bps slow-trend reversal, with a 120-bar re-entry cooldown. Dev PnL +$26.84 on the frozen 24h window (2 fills, max drawdown 1.98%).
